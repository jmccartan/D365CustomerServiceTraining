# Copilot Studio Training — Curated Learning Guide

A curated, shareable list of the **best training options for Microsoft Copilot Studio**, centered on three high-value sources: **Microsoft Learn** (free & official), **Agent Academy** (gamified, mission-based), and **Pluralsight** (polished video, subscription-based).

> Tip: If you're building agents for **Dynamics 365 Customer Service**, Copilot Studio is the low-code home for custom copilots/agents, topics, and generative answers. Start free with Microsoft Learn, reinforce with Agent Academy, then fill governance/admin gaps with Pluralsight.

## 1. Microsoft Learn (Start Here — Free & Official)

The authoritative, free, official source. Best place to build a solid foundation.

- [Get started with Microsoft Copilot Studio (learning path)](https://learn.microsoft.com/en-us/training/paths/work-power-virtual-agents/) — The main structured learning path; the recommended starting point.
- [Get started with Copilot Studio bots (module)](https://learn.microsoft.com/en-us/training/modules/power-virtual-agents-bots/) — Core "get started" module; grounding in agents, topics, and publishing.
- [Create copilots with Microsoft Copilot Studio (module)](https://learn.microsoft.com/en-us/training/modules/create-copilots-copilot-studio/) — Hands-on building of custom copilots/agents.
- [Manage topics in Copilot Studio (module)](https://learn.microsoft.com/en-us/training/modules/manage-power-virtual-agents-topics/) — Authoring and managing conversation topics.
- [Browse all Copilot Studio training](https://learn.microsoft.com/en-us/training/browse/?terms=Copilot%20Studio) — Search entry point for every Learn module and path on the topic.

---

## 2. Agent Academy (Gamified, Mission-Based)

A gamified, mission-based learning experience that ramps you from beginner to advanced through tiered "missions."

- [Agent Academy](https://aka.ms/agent-academy) — The hub for the mission-based program.

**Tiers / tracks:**
- **Recruit** — Entry-level fundamentals; ideal first stop after the Learn "Get started" module.
- **Operative** — Intermediate agent-building skills.
- **Commander** — Advanced design, orchestration, and scale.
- **Special Ops** — Specialized/advanced scenarios.
- **Cowork Collective** — Community and collaborative learning.

## Recommended Learning Order

1. **Start** with the Microsoft Learn ["Get started" module](https://learn.microsoft.com/en-us/training/modules/power-virtual-agents-bots/) to build fundamentals for free.
2. **Progress** through [Agent Academy](https://aka.ms/agent-academy) — **Recruit → Operative** — for hands-on, gamified reinforcement.
3. **Supplement** with [Pluralsight](https://www.pluralsight.com/search?q=Copilot%20Studio&type=course) for polished video and to fill governance/admin gaps.
4. **Finish** the [Microsoft Learn learning path](https://learn.microsoft.com/en-us/training/paths/work-power-virtual-agents/) and pursue the **Applied Skills** credential.

## Credentials

- **Microsoft Applied Skills** — Scenario-based, verifiable credentials that validate hands-on Copilot Studio / agent-building skills. Browse via the [Microsoft Learn training catalog](https://learn.microsoft.com/en-us/training/browse/?terms=Copilot%20Studio).
